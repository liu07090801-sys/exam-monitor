
======================================================
    考试监控 - 监考端启动说明
======================================================

前提：本机已安装 Python 3.10+

一、启动
  双击【启动监考端.bat】（或命令行执行 python server.py）
  看到"监考中心"仪表盘窗口即启动成功

  首次必做：放行防火墙 8765 端口（以管理员身份打开 CMD，执行）
    netsh advfirewall firewall add rule name="考试监控8765" dir=in action=allow protocol=TCP localport=8765
  首次启动如弹出 Windows 防火墙提示，点「允许访问」亦可。
  若考生端连不上，多半是这条没放行。

二、确认考生连接
  - 监考端窗口底部会显示「考生端请填 IP: x.x.x.x」，考生端输入该 IP 即可
    （也可编辑 config.yaml 的 network.advertise_ip 手动指定本机 IP）
  - 考生上线后左侧出现卡片，状态灯变绿即正常
  - 点击卡片可在右下角预览该考生屏幕截图

三、日常操作
  - 状态灯：绿=正常 / 红=报警 / 灰=离线
  - 出现报警：日志栏查看原因，点考生卡片看截图判断
  - 结束监考：点顶部「结束监考」按钮（所有考生端自动退出）
  - 导出日志：点顶部「导出日志」按钮（生成CSV文件到 exports/ 目录）

四、配置修改
  编辑同目录 config.yaml，重启程序生效
  - token：令牌（考生端必须一致）
  - network.advertise_ip：本机 IP（留空=自动探测）
  - exam.url_whitelist：考试网址白名单
  - server.teacher_password：监考口令（空=不校验）
