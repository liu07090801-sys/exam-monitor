# 屏幕监控系统 — 使用说明

> 基于 WebSocket 的实时屏幕监控方案，适用于单场考试场景。
> 监考端接收所有考试端的截屏、窗口切换报警和心跳状态，并通过可视化仪表盘集中展示。

## 1. 系统架构

```
┌──────────────────┐     WebSocket      ┌──────────────────┐
│    监考端 Server  │◄══════════════════►│   考试端 Client  │
│  (server.py)     │                     │  (client.py)     │
│                  │                     │                  │
│  • 接收截屏      │  ◄── 二进制帧(JPEG) │  • 定时截屏      │
│  • 接收报警      │  ◄── JSON(切屏事件) │  • 窗口焦点检测  │
│  • 心跳监测      │  ◄── JSON(心跳)     │  • 变化检测      │
│  • 可视化仪表盘  │  ──► JSON(控制指令)  │  • 考试网址+全屏强制│
│  • 日志持久化    │                     │  • 报警即截图取证  │
└──────────────────┘                     └──────────────────┘
        │                                        │
        ▼                                        ▼
   monitor.db                              （截图仅上传
   exports/                                 不存本地）
```

**通信协议：**
- 心跳、报警、注册等控制消息：JSON over WebSocket
- 截图数据：直接发送 JPEG 二进制帧（高效，无 base64 开销）
- 认证方式：Token 令牌校验

## 3. 安装依赖

```bash
pip install -r requirements.txt
```

依赖列表：

| 包名 | 用途 |
|------|------|
| `mss` | 高性能跨平台截屏 |
| `Pillow` | 图像处理（压缩、缩放、拼接） |
| `websockets` | WebSocket 通信 |
| `psutil` | 获取前台窗口进程名（可选，缺失时降级为纯标题匹配） |
| `uiautomation` | 读取浏览器地址栏 URL（可选，缺失时考试网址检测降级为标题匹配） |
| `pyyaml` | 读取 config.yaml 配置文件 |

> **说明**：`uiautomation` 仅在考试端（Windows）用于读取浏览器地址栏，缺失时系统自动降级为标题匹配；监考端无需安装。

## 4. 快速开始

### 第一步：启动监考端

在监考老师的机器上运行：

```bash
python server.py
```

启动后显示监考中心仪表盘，监听端口 `8765`。

### 第二步：启动考试端

在每台考生机器上运行：

```bash
python client.py --student-id 2024001
```

默认连接 `ws://127.0.0.1:8765`（本机测试）。
连接真实监考端时指定地址：

```bash
python client.py --server ws://192.168.1.100:8765 --student-id 2024001
```

### 第三步：开始监控

考生端启动后自动进入全屏锁定模式，开始截屏和窗口检测。
监考端仪表盘实时显示各考生状态。

## 5. 配置说明

所有配置集中在 `config.yaml`，修改后重启程序生效。

### 5.1 网络配置

```yaml
network:
  host: "0.0.0.0"       # 监听地址（0.0.0.0 = 所有网卡）
  port: 8765             # 监听端口
  token: "exam2024"      # 认证令牌（客户端必须携带相同值）
```

> **安全提示**：正式考试请修改 `token` 为复杂随机字符串，防止未授权接入。

### 5.2 截屏配置

```yaml
screenshot:
  interval: 5            # 截屏间隔（秒），建议3~10
  quality: 60            # JPEG压缩质量（1-100），越小文件越小
  dir: "screenshots"     # 本地截图保存目录
  retention_days: 7      # 截图保留天数，超过自动清理
  multi_monitor: true    # 多显示器时是否拼接所有屏幕
```

### 5.3 变化检测

```yaml
hash:
  size: 16               # 感知哈希尺寸（16×16=256bit）
  send_threshold: 24     # 汉明距离≥此值才上传截图（明显变化）
  local_threshold: 4     # 汉明距离≥此值才本地存档
  force_send_interval: 30 # 强制上传间隔（秒，防冻结）
```

**调参建议：**
- `send_threshold` 调低 → 更敏感，上传更频繁
- `send_threshold` 调高 → 更宽松，只在大变化时上传
- `force_send_interval` 确保即使画面静止，监考端也能定期收到截图验证

### 5.4 窗口检测

```yaml
window:
  check_interval: 1           # 检测间隔（秒）
  violation_confirm_count: 3  # 连续违规次数阈值（过滤误触）
  whitelist:                  # 窗口标题白名单（包含任一关键词即合法）
    - "洛谷"
  whitelist_processes: []     # 进程名白名单（可空）
```

**白名单示例：**
```yaml
whitelist:
  - "洛谷"
  - "考试系统"
  - "在线考试"

whitelist_processes:
  - "exam.exe"
  - "chrome.exe"
```

> 前台是浏览器进程时，改按 5.7「考试网址与全屏强制」判定（URL + 全屏）；其他窗口才按本节白名单判定。

### 5.5 客户端配置

```yaml
client:
  heartbeat_interval: 3       # 心跳间隔（秒）
  connect_timeout: 5          # 连接超时（秒）
  reconnect_base_delay: 2     # 断线重连基础延迟（秒）
  reconnect_max_delay: 30     # 断线重连最大延迟（秒，指数退避上限）
  lock_mode: "popup"          # popup=违规时才弹出锁定界面（推荐）；overlay=全程全屏锁定
  alert_hold_seconds: 0       # popup 违规警示保持秒数，0=保持到考生恢复合规
```

**lock_mode 说明**：

- `popup`（默认）：监控窗口平时隐藏，**不遮挡考试画面、不会出现在截图中**；检测到违规时才弹出全屏警示，考生恢复合规后自动收起；断线时弹出角落状态窗（不阻塞考试），重连自动隐藏。
- `overlay`（旧行为）：全程全屏锁定。若考试软件不是置顶窗口会被锁定界面遮挡，**截屏将一直是锁定画面**，仅建议在必须全程锁屏的场景使用。

### 5.6 监考端配置

```yaml
server:
  client_timeout: 15          # 超时掉线阈值（秒）
  freeze_timeout: 90          # 在线但超过此秒数无截图帧视为画面冻结
  alert_hold_seconds: 300     # 状态灯红色保持时长（秒），超时自动恢复绿色
  alert_flash_duration: 3000  # 报警横幅显示时长（毫秒）
  max_screenshot_history: 200 # 每考生最大截图历史条数（内存，供翻页浏览）
  max_screenshots_disk: 0     # 落盘截图数量上限（0=不限制，仅按 retention_days 清理）
  preview_refresh_ms: 2000    # 截图预览刷新间隔（毫秒）
  db_file: "monitor.db"       # SQLite数据库文件
  cleanup_interval: 3600      # 过期数据清理间隔（秒）
  teacher_password: ""        # 非空时「结束监考/导出日志」需输入此口令
```

- **alert_hold_seconds**：考生卡片红灯在最近一次报警后保持该秒数，随后自动恢复绿色；持续违规会不断刷新该窗口，保持红色。
- **teacher_password**：留空表示不校验（原行为）；配置后「结束监考」和「导出日志」均需输入口令，防止误触。

### 5.7 考试网址与全屏强制

```yaml
exam:
  enabled: true                # 是否强制浏览器停留在考试网址且全屏
  url_whitelist:               # 考试网址白名单（域名，或 域名/路径 前缀）
    - "luogu.com.cn"
  browsers:                    # 需要校验网址的浏览器进程
    - "chrome.exe"
    - "msedge.exe"
    - "firefox.exe"
  fullscreen_required: true    # 浏览器必须全屏（F11）
  grace_seconds: 30           # 启动宽限期（秒）
  strict_url_check: false      # 读不到网址时是否直接判违规
```

规则说明：

- 前台窗口是 `browsers` 中的浏览器时，必须满足：**全屏** 且地址栏 URL 命中 `url_whitelist`（域名相等或为其子域，带路径的条目按路径前缀匹配），否则判违规并**报警 + 截图取证**。
- 宽限期 `grace_seconds` 内任何窗口暂不判违规，供考生打开浏览器、登录并进入考试页（建议按实际准备时间调整）。
- 地址栏通过 UI Automation 读取；未安装 `uiautomation` 或读取失败时，`strict_url_check: false` 退回标题白名单判断，`true` 直接判违规（更严格，但可能因读取失败误报）。
- 非浏览器窗口仍按 5.4 的标题/进程白名单判定。

### 5.8 TLS 加密（WSS）

```yaml
tls:
  enabled: false              # 是否启用 WSS 加密
  cert_file: "cert.pem"       # 服务端证书
  key_file: "key.pem"         # 服务端私钥
  ca_file: "ca.pem"           # 客户端信任的 CA 证书（可选）
```

启用方法：

1. 生成自签名证书（考试内网场景够用）：
   ```bash
   openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 30 -nodes -subj "//CN=monitor"
   ```
2. 把 cert.pem / key.pem 放到程序目录，tls.enabled 改为 true；
3. 客户端启动时地址使用 wss://监考端IP:8765。

> **安全说明**：配置了 ca_file 时客户端严格校验服务端证书；未配置时降级为不校验（仅限可信内网自签名场景）。证书缺失时服务端拒绝启动，避免“以为加密实际明文”的隐患。

## 6. 功能详解

### 6.1 监考端仪表盘

| 区域 | 功能 |
|------|------|
| **顶部状态栏** | 显示端口、认证状态、在线人数和总报警数 |
| **考生卡片** | 每个考生一张卡片，显示状态灯（绿=正常/红=报警/灰=离线）、主机名、截屏数、报警数 |
| **事件日志** | 右侧实时滚动日志，记录上线/离线/报警/冻结等事件 |
| **截图预览** | 点击考生卡片，在右下角预览该考生最新截图 |
| **导出日志** | 将事件日志导出为 CSV 文件（保存到 `exports/` 目录；配置了口令时需验证） |
| **结束监考** | 向所有在线考生发送结束指令，客户端自动退出（配置了口令时需验证） |

### 6.2 考试端客户端

| 功能 | 说明 |
|------|------|
| **锁定模式** | `popup`：窗口平时隐藏、违规时弹出全屏警示，不遮挡考试画面；`overlay`：全程全屏锁定（旧行为） |
| **考试网址强制** | 浏览器必须全屏且停留在白名单考试网址（洛谷），切换/退出网址、未全屏均报警 |
| **报警即截图** | 确认违规瞬间立即抓屏、本地存档并上传取证，先取证后弹警示 |
| **自动截屏** | 按配置间隔截屏，通过感知哈希判断画面变化，仅变化时上传 |
| **窗口检测** | 每秒检测前台窗口，白名单外的窗口连续出现3次即报警 |
| **本地存档** | 截图同步保存到本地 `screenshots/学号/日期/` 目录 |
| **断线重连** | 网络断开后自动重连，延迟指数增长（2s→4s→8s→...→30s） |
| **状态显示** | 顶部显示连接状态、当前窗口、截屏数和报警数 |

### 6.3 安全机制

| 机制 | 说明 |
|------|------|
| **Token认证** | 客户端注册时必须携带正确令牌，错误则拒绝连接 |
| **二进制帧传输** | 截图以原始 JPEG bytes 传输，不经过 base64 编码，减少33%带宽开销 |
| **连续违规确认** | 窗口切换需连续检测到3次才报警，过滤鼠标误点和弹窗闪烁 |
| **冻结检测** | 考生在线但超过 `freeze_timeout` 秒未收到任何截图帧时报警（静止画面由 `force_send_interval` 定期补帧，属正常） |
| **考试网址+全屏强制** | 浏览器全屏 + 地址栏 URL 白名单双重校验，退出考试网址立即报警 |
| **报警即截图** | 违规瞬间先抓屏取证再弹警示，确保证据画面不含警示遮罩 |
| **TLS加密** | 可选 WSS 加密，配置证书后服务端/客户端自动启用 |

## 7. 操作流程

### 7.1 考前准备

1. 确保所有机器在同一局域网，端口 8765 可互通
2. 监考端与考生端均需放行防火墙 8765 端口（以管理员身份运行）：

   **Windows（推荐，只放行端口）：**
   ```powershell
   netsh advfirewall firewall add rule name="考试监控8765" dir=in action=allow protocol=TCP localport=8765
   ```

   首次启动时如弹出 Windows 防火墙提示，请点「允许访问」。

   **如需临时关闭防火墙（不推荐，测完记得开启）：**
   打开 Windows 安全中心 → 防火墙和网络保护 → 关闭 Microsoft Defender 防火墙

3. 修改 `config.yaml` 中的 `token`（建议使用复杂随机字符串）
4. 根据考试需求调整白名单、截屏间隔等参数
5. 在所有考试端安装依赖：`pip install -r requirements.txt`

### 7.2 考试期间

1. **监考老师**先启动 `python server.py`
2. **考生**依次启动 `python client.py --student-id 学号 --server ws://监考端IP:8765`
3. **考生**在宽限期（`exam.grace_seconds`，默认 30 秒）内打开浏览器，进入洛谷考试网址并按 F11 全屏，超时未就位将报警
4. 监考端仪表盘实时显示所有考生状态
5. 发现异常（切屏/网址/未全屏报警、画面冻结、掉线）时及时处理

### 7.3 考试结束

1. 监考老师点击「结束监考」按钮
2. 所有考生端收到指令后自动退出全屏并关闭
3. 点击「导出日志」保存本次考试的完整事件记录

## 8. 日志与数据

### 8.1 数据库

程序运行生成 `monitor.db`（SQLite），包含两张表：

**events 表 — 事件日志**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 自增主键 |
| ts | REAL | Unix 时间戳 |
| client_id | TEXT | 考生学号 |
| kind | TEXT | 事件类型（register/violation/freeze/timeout/offline） |
| detail | TEXT | 事件详情 |

**screenshots 表 — 截图索引**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 自增主键 |
| ts | REAL | Unix 时间戳 |
| client_id | TEXT | 考生学号 |
| path | TEXT | 截图文件路径 |
| hash_hex | TEXT | 感知哈希（十六进制） |

### 8.2 截图目录

```
screenshots/
├── 2024001/                  # 考生学号
│   ├── 2026-08-17/           # 日期
│   │   ├── 160752.jpg        # 时间戳命名
│   │   ├── 160758.jpg
│   │   └── ...
│   └── 2026-08-18/
│       └── ...
└── 2024002/
    └── ...
```

### 8.3 导出日志

点击监考端「导出日志」按钮，生成 CSV 文件到 `exports/` 目录：

```
exports/
└── monitor_log_20260817_161344.csv
```

CSV 格式（UTF-8 with BOM，Excel 可直接打开）：

```csv
时间,考生,类型,详情
2026-08-17 16:12:28,2024001,register,考生上线: 2024001 (WIN-QNVME2PTKS9)
2026-08-17 16:12:32,2024001,violation,考生 2024001 切屏 -> 监考中心
```

### 8.4 自动清理

- 截图文件和数据库记录按 `retention_days`（默认7天）自动清理
- 清理周期由 `cleanup_interval`（默认3600秒）控制
- 设为0可禁用自动清理
- `max_screenshots_disk`（默认0=不限制）可设置落盘截图总量上限，超过后删除最旧记录

## 9. 常见问题

### Q: 客户端提示"连接断开，重连中..."

**原因：** 监考端未启动，或网络不通。

**解决：**
1. 确认监考端已启动且端口正确
2. 检查防火墙是否放行 8765 端口
3. 用 `ping` 测试网络连通性

### Q: 客户端提示"认证失败：令牌不正确"

**原因：** 客户端与监考端的 token 不一致。

**解决：** 确认双方使用同一个 `config.yaml`，或手动指定相同 token。

### Q: 监考端看不到考生截图

**原因：** 截图变化太小未触发上传。

**解决：**
- 调低 `config.yaml` 中的 `hash.send_threshold`（如改为 10）
- 缩短 `hash.force_send_interval`（如改为 15）加快强制上传频率

### Q: 出现“画面冻结”报警

**原因：** 考生在线但超过 `freeze_timeout` 秒没有任何截图帧到达。可能原因：
1. 考生杀掉了客户端进程或断网但心跳仍被转发（少见）；
2. 客户端卡死；
3. 考生使用了虚拟桌面/远程桌面等工具。

**处理：** 结合截图预览人工判断，如确认作弊则记录。静止画面属正常现象，不会触发本报警。

### Q: 考生端误触切屏后如何撤销报警？

**无法撤销。** 报警记录永久保存在数据库中。连续违规确认机制（默认3次）已尽量减少误报。

### Q: 如何支持多考场？

当前版本为单考场设计。多考场可通过以下方式实现：
1. 不同考场使用不同端口（修改 `config.yaml` 的 `port`）
2. 监考端分别启动多个 `server.py` 实例

### Q: 如何查看历史截图？

1. 监考端点击考生卡片上的「查看截图」按钮
2. 支持翻页浏览，每页20张
3. 截图文件也保存在本地 `screenshots/` 目录，可直接用图片浏览器查看

### Q: 客户端会不会把自己锁定窗口当成切屏报警？

**不会。** 客户端在焦点检测中按窗口句柄（HWND）豁免自身窗口，锁定/警示界面出现在前台时不会自我报警；考生恢复合规后警示界面自动收起。

### Q: 考试网址检测没生效（考生切到别的网页没报警）？

**原因：** 考试端未安装 `uiautomation`，网址检测降级为标题匹配。

**解决：** 在考试端执行 `pip install uiautomation`，或在 `config.yaml` 中把 `exam.strict_url_check` 设为 `true`（读不到网址直接判违规）。

### Q: 截图全是锁定界面，看不到考生屏幕？

**原因：** `client.lock_mode` 为 `overlay`（旧行为），锁定窗口全程置顶全屏，遮挡了考试软件。

**解决：** 改为 `popup`（默认）：监控窗口平时隐藏，只有违规时才弹出警示，截屏记录的是真实考试画面。

## 命令行参数

### server.py

```bash
python server.py
```

无需参数，所有配置通过 `config.yaml` 管理。

### client.py

```bash
python client.py --student-id <学号> [--server ws://<地址>:<端口>]
```

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--student-id` | ✅ | — | 考生学号（唯一标识） |
| `--server` | ❌ | `ws://127.0.0.1:8765` | 监考端 WebSocket 地址 |

**示例：**
```bash
# 连接本机（调试用）
python client.py --student-id 2024001

# 连接远程监考端
python client.py --server ws://192.168.1.100:8765 --student-id 2024001
```
